## 🔧 **COMO USAR AS TRADUÇÕES**

### **1. No Componente**
```tsx
import { useTranslations } from 'next-intl';

export function HeroContent() {
  const t = useTranslations('home');
  
  return (
    <div>
      <h1>{t('hero.title')}</h1>
      <p>{t('hero.subtitle')}</p>
    </div>
  );
}
```

### **2. Namespaces**
```tsx
// Para traduções comuns
const t = useTranslations('common');

// Para traduções específicas da página
const t = useTranslations('home');
const tPortfolio = useTranslations('portfolio');
```

### **3. Interpolação**
```tsx
// Para textos com variáveis
const t = useTranslations('common');
<p>{t('welcome', { name: 'Elias' })}</p>
```
