# Fila de Atendimento - Chat Omnichanel

## 📋 Componentes

Este case study é composto pelos seguintes componentes:

### Seções Principais
- **HeroSection**: Apresentação inicial com título e estatísticas
- **IntroductionSection**: Introdução ao projeto e contexto
- **ProblemSection**: Identificação do problema a ser resolvido
- **SolutionSection**: Apresentação da solução proposta
- **FeaturesSection**: Funcionalidades principais do sistema
- **UXProcessSection**: Metodologia e processo de UX utilizado
- **ResultsSection**: Resultados e impacto do projeto
- **CallToActionSection**: Chamada para ação final

### Estrutura
```
fila-atendimento/
├── index.ts                    # Exports dos componentes
├── HeroSection.tsx            # Hero principal
├── IntroductionSection.tsx    # Introdução
├── ProblemSection.tsx         # Problema
├── SolutionSection.tsx        # Solução
├── FeaturesSection.tsx        # Funcionalidades
├── UXProcessSection.tsx       # Processo UX
├── ResultsSection.tsx         # Resultados
├── CallToActionSection.tsx    # CTA
└── README.md                  # Esta documentação
```

## 🎨 Design System

Seguindo o mesmo padrão dos outros cases do portfólio:
- Tipografia consistente
- Sistema de cores harmônico
- Animações suaves com Framer Motion
- Layout responsivo
- Componentes reutilizáveis
